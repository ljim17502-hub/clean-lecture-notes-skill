# 质量检查清单

最终交付前使用本清单。

## 逐字稿清洗

- [ ] 原始逐字稿仍然可用且未被修改，除非用户明确要求更新。
- [ ] 口头填充词、重复片段和破碎 ASR 标点已清理。
- [ ] 老师案例、产品名、数字、作业和提醒已保留。
- [ ] 不确定更正已标注，没有被编造成确定事实。
- [ ] 清洗稿有可用标题。

## 学习笔记

- [ ] 笔记顶部包含 `思维导图` 或等价结构总览。
- [ ] 如果写入飞书，`思维导图` 是 Mermaid flowchart 或等价可视化白板，不是纯文本树状代码块。
- [ ] 笔记包含按时间划分的复习路径，或清晰的学习说明。
- [ ] 核心结论位于密集细节之前。
- [ ] 笔记包含主动回忆问题。
- [ ] 概念按模块、认知模型或章节分组。
- [ ] 案例贴在它们解释的概念旁边。
- [ ] 重点关键词和高价值句子已加粗，且没有整段过度加粗。
- [ ] 相关时，包含练习、面试或项目迁移章节。
- [ ] 资料来源已列出。
- [ ] 对较完整的笔记，包含最终学习者质量审计。
- [ ] 正文是学习者复习/迁移视角，不是课堂旁听记录、会议纪要或转述稿。
- [ ] 没有“谁讲了什么、课程怎样发生、材料末尾有什么”的旁观者叙述。
- [ ] 每段都能回答“我应该记住什么 / 怎么用 / 怎么迁移”。
- [ ] 最终学习笔记没有独立 `待确认` 章节；可推断术语已归一化，无法确认且影响事实的内容只放在质量审计。

## 飞书输出

- [ ] 默认新建文档，或用户已明确批准编辑已有文档。
- [ ] 写入后成功拉取大纲。
- [ ] 大纲确认第一个正文标题是 `思维导图`。
- [ ] 关键词拉取确认重要章节存在。
- [ ] 拉取 `思维导图` 章节，确认存在 `whiteboard type="mermaid"` 或等价 Mermaid 内容，且没有旧 `pre/code` 树状图替代导图。
- [ ] 所有图示或白板都不是空的；能导出缩略图时，确认缩略图非空且可读。
- [ ] 本地中间文件已保留，或已说明删除情况。

## 逻辑一致性

- [ ] 当来源噪声较多时，笔记没有跳过逐字稿清洗。
- [ ] 有课件时，课件被用作结构来源。
- [ ] 除非逐字稿中明确修正课件，逐字稿案例不覆盖课件定义。
- [ ] 清洗稿和最终学习笔记的分工清楚：清洗稿可保留课堂顺序、说话人和待确认；学习笔记必须转成复习结构。
- [ ] 最终回复说明了校验结果和剩余限制。
