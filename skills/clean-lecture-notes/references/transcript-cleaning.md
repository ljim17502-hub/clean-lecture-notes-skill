# 逐字稿清洗

清洗课堂录音、飞书逐字稿、本地 ASR 输出或复制来的授课文本时，使用本参考。

## 目标

- 保留原意、事实、顺序、例子、决策和老师强调的内容。
- 通过移除 ASR 噪声、口头填充词、重复片段、破碎标点和过长段落来提升可读性。
- 保持不确定性可见。如果姓名、数字、术语或产品名可能识别错误，要标注为待确认，而不是悄悄改成确定说法。

## 清洗步骤

1. 规范说话人：
   - 只有当说话人标签有助于理解问答或讨论时，才保留标签。
   - 同一说话人的连续段落如果属于同一个意思，应合并。
   - 只有在角色明确时，才把 `发言人 1` 这类泛化标签改成 `老师`、`学生` 等中性标签。
2. 移除口语噪声：
   - 删除口头填充词、重复开头、意外打断和明显的转写卡顿。
   - 如果反问句用于教学，应保留。
   - 玩笑或闲聊只有在解释概念或课堂要求时才保留。
3. 修复结构：
   - 按主题拆分长段落。
   - 根据课程推进添加简洁小标题。
   - 除非用户要求按主题重组清洗稿，否则保留时间顺序。
4. 更正明显的 ASR 错误：
   - 当上下文足以判断时，更正产品名、技术术语、缩写和常见课程词汇。
   - 不要把模糊表达“升级”为精确断言。
   - 只有在更正不确定时，才把原始说法放在括号中保留。
5. 提取可复用素材：
   - 标记关键定义、例子、老师提醒、作业和项目建议。
   - 为学习笔记阶段创建一个简短的“可能的笔记锚点”列表。

## 不要做什么

- 不要把后续笔记可能需要的细节概括掉。
- 如果老师的回答依赖学生问题，不要删除该问题。
- 不要编造缺失的课件、日期、指标、URL、产品说法或引用来源。
- 默认不要覆盖源文档。

## 清洗稿结构

除非用户另有要求，使用以下结构：

```markdown
# 清洗稿｜<课程或主题>｜<日期>

## 一句话概览

## 主题 1

### 关键讲解

### 课堂案例

### 老师强调

## 主题 2

## 待确认
- [ ] 可能识别错误的词：
- [ ] 需要回看课件的位置：
```

## 完成标准

- 读者可以在没有 ASR 干扰的情况下理解课程。
- 重要例子仍然贴在它们解释的概念旁边。
- 不确定术语没有被悄悄改写成确定断言。
- 清洗稿可以作为生成学习笔记的可靠输入。
